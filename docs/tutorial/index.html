YierPet Win 一二桌宠

Windows 桌面上的「一二」——安装、运行与日常使用说明

仓库：gitee.com/cat_10/YierPet4Win 平台：Windows 10 / 11 推荐：Release 压缩包，解压即用

0. 太长不看 · 两种安装方式

方法一：下载 Release 压缩包（推荐）

不用装 Git，不用编译，解压后双击即可。

  1. 打开 Release 页面

    gitee.com/cat_10/YierPet4Win/releases

  2. 下载安装包

    下载最新版 YierPet4Win-win-x64.zip（自包含版，无需另装 .NET）。

  3. 解压并运行

    解压到任意文件夹（如桌面），双击 YierPet.exe。桌面上会出现「一二」。

若 Windows 提示「未知发布者」：点「更多信息」→「仍要运行」；或右键 exe → 属性 → 勾选「解除锁定」。

方法二：Gitee 克隆源码自己编译

适合开发者或 Release 尚未更新时。需要先安装 .NET 8 SDK（不是仅 Runtime）：

https://dotnet.microsoft.com/download/dotnet/8.0

装完后新开终端，执行 dotnet --version，应显示 8.x。

  1. 克隆仓库
    git clone https://gitee.com/cat_10/YierPet4Win.git
cd YierPet4Win
  2. 构建

    若提示禁止运行脚本，先执行一次：

    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

    然后构建：

    powershell -ExecutionPolicy Bypass -File .\build.ps1
  3. 启动
    .\build\YierPet.exe

    任务栏通常不会出现常驻按钮，这是正常的。

1. 方法一：Release 压缩包（详细）

  1. 打开 Gitee Releases；
  2. 下载 YierPet4Win-win-x64.zip；
  3. 右键 zip → 解压到当前文件夹（或「全部解压缩」）；
  4. 进入解压后的文件夹，双击 YierPet.exe。
Release 包为自包含版，已内置 .NET 运行时，不需要安装 SDK 或 Runtime，也不需要 Git。

建议把整个文件夹放在固定位置（如 D:\Apps\YierPet4Win），不要只复制 exe 而漏掉同目录下的 Assets 等文件。

2. 方法二：克隆源码编译（详细）

开始之前

  • 操作系统：Windows 10（1809 及以上）或 Windows 11。
  • 编译：需要 .NET 8 SDK。
  • Git：用于 git clone。

步骤

git clone https://gitee.com/cat_10/YierPet4Win.git
cd YierPet4Win
powershell -ExecutionPolicy Bypass -File .\build.ps1
.\build\YierPet.exe

也可在资源管理器中双击 build\YierPet.exe 启动。框架依赖版需另装 .NET 8 桌面运行时；打 Release 包请用 .\build.ps1 -Package -SelfContained。

路径作用
Assets\精灵图集与表情包
YierPet\源代码
build\构建产物

3. 这是什么

YierPet Win 是一只住在 Windows 桌面上的透明悬浮小宠物。 它会自己散步、跳跃、挥手；可以拖拽和「甩出去」玩物理抛掷； 还会在合适的时候用头顶气泡提醒你喝水、起身、别熬夜，并在 CPU 飙高时「红温」。

本仓库自带精灵图与表情包（Assets/），与 macOS 版能力对齐，但独立发布，不依赖 Mac 项目。 运行不需要辅助功能、屏幕录制等敏感权限。

4. SmartScreen / 杀毒软件拦截

未签名的 exe 可能被 Windows Defender SmartScreen 提示「未知发布者」。

常见处理：

  1. 在警告窗口点「更多信息」→「仍要运行」；或
  2. 右键 YierPet.exe → 属性 → 若底部有「解除锁定」，勾选后确定，再双击运行。

Release 下载版与自行编译版都可能出现此提示，属正常现象。

5. 开机自启（可选）

  1. 对 YierPet.exe 右键 → 创建快捷方式；
  2. 按 Win + R，输入 shell:startup 回车，打开「启动」文件夹；
  3. 把快捷方式拖进该文件夹；
  4. 建议把桌宠文件夹放在固定路径（如 D:\Apps\YierPet4Win），避免移动后快捷方式失效。

下次登录 Windows 后，一二会自动出现在桌面。

7. 右键菜单

  • 形象 — 经典一二 / 活力一二 / 活力布布 / 一二布布（自动保存）；
  • 动作 — 仅「经典一二」，手动切换 9 种图集动作；
  • 暂停随机行为 / 开启随机行为；
  • 提醒设置 — 久坐、喝水、深夜、摸鱼；
  • 系统哨兵 — CPU、内存、电量、磁盘；
  • 陪伴模式 — 早晨、午饭、下午茶、周五、编码久战；
  • 退出 — 关闭应用。
隐藏功能：按住 Alt 再右键，会出现「测试提醒」，可立即触发各类提醒，方便录视频或自查效果。

8. 健康提醒与系统哨兵（概要）

健康提醒

类型大致触发条件
久坐提醒连续在电脑前活跃约 1 小时（离开 5 分钟会清零）
喝水提醒约每 30 分钟（人不在时不计时）
深夜关怀23 点后待机动画变慢；若仍在工作，约每 30 分钟关怀一次
摸鱼检测视频类程序连续前台约 30 分钟（如 B 站客户端、PotPlayer、腾讯视频等，按进程名识别）

系统哨兵

CPU 持续偏高、内存负载过高、低电量、磁盘空间不足等会冒气泡。CPU 红温时经典版会逐渐变红；「活力一二」表情包有着火动画。

任意两类提醒之间约 90 秒 间隔。设置保存在 %AppData%\YierPetWin\settings.json。

11. 常见问题

Release 和源码编译有什么区别？

Release 压缩包解压即用；源码编译需要 .NET 8 SDK 和 Git，适合开发者。

任务栏里找不到 YierPet？

设计为不占用任务栏主按钮。请右键宠物 →「退出」。

.\build.ps1 报缺少 Assets？

确认克隆的是完整仓库，根目录应有 Assets\spritesheet.webp 和 Assets\Packs\。

双击 exe 没反应？

先安装 .NET 8 桌面运行时；或在终端运行 .\build\YierPet.exe 查看错误信息。

需要管理员或特殊权限吗？

不需要。空闲时间与前台程序检测使用 Windows 公开 API。

摸鱼检测认不出我的播放器？

在源码 YierPet\ActivityMonitor.cs 的 SlackProcessNames 中加入该程序的进程名（任务管理器 → 详细信息 → 名称，不含 .exe）。

想改台词或提醒间隔？

编辑 YierPet\ReminderCenter.cs 后重新 .\build.ps1。手感参数在 PetController.cs 顶部。

如何打开本教程？

双击 docs\tutorial\index.html，或用浏览器打开该文件即可（可离线观看、适合录安装视频时对照）。

12. 如何退出

右键点击桌面上的宠物 → 选择退出。
